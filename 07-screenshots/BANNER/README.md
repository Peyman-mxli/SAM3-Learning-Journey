# Screenshots

This directory contains screenshots documenting the setup process, experiments, practical exercises, execution results, and development progress throughout the **SAM3 Learning Journey**.

The screenshots provide visual evidence of the different environments, tools, models, notebooks, and Computer Vision workflows used during the course.

---

## Purpose

The `07-screenshots` directory is used to:

- Document important development steps.
- Preserve visual evidence of successful executions.
- Record Google Colab environments and GPU configurations.
- Capture Computer Vision detection, segmentation, and tracking results.
- Document experiments and troubleshooting.
- Support the technical documentation contained in the repository.
- Provide visual references for projects and course notes.
- Track the evolution of the SAM3 Learning Journey.

## Recommended Naming Convention

Screenshots should use descriptive filenames instead of generic names such as:

```text
Screenshot1.png
image.png
capture.png
```

Preferred examples:

```text
google-colab-t4-gpu.png
sam3-segmentation-result.png
yolo-detection-output.png
bytetrack-object-tracking.png
video-tracking-result.png
sqlite-analytics-result.png
trajectory-visualization.png
computer-vision-pipeline-test.png
```

This makes screenshots easier to identify and reference throughout the repository.

## Using Screenshots in Markdown

Screenshots can be displayed in repository documentation using standard Markdown:

```markdown
![SAM3 Segmentation Result](../../07-screenshots/sam3-segmentation-result.png)
```

Or with HTML when additional control over alignment and size is required:

```html
<p align="center">
  <img src="../../07-screenshots/sam3-segmentation-result.png"
       alt="SAM3 Segmentation Result"
       width="800">
</p>
```

Always verify the relative path from the Markdown file where the screenshot is being referenced.

---

## Documentation Principle

Screenshots should complement the technical documentation rather than replace it.

Whenever possible, each important screenshot should be accompanied by an explanation describing:

- What is being demonstrated.
- Which tool or model was used.
- What input was processed.
- What result was obtained.
- Why the result is relevant.

This keeps the repository useful not only as a record of completed work, but also as a learning resource for other students and developers.
