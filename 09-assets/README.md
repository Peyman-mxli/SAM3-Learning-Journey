# 🖼️ Assets

Welcome to the **Assets** directory of the **SAM3 Learning Journey** repository.

This folder contains all visual resources used throughout the documentation. Keeping images in a single location helps maintain a clean repository structure, avoids duplication, and makes future updates easier.

# 💡 Why Use a Central Assets Folder?

Using a centralized assets folder provides several advantages:

- Better project organization
- Easier maintenance
- No duplicated images
- Consistent design across the repository
- Professional GitHub repository structure

---

# 🚀 Usage Example

Images are referenced from anywhere in the repository using relative paths.

Example:

```markdown
<p align="center">
  <img src="../../09-assets/banners/GitHub-Banner.png" width="100%">
</p>
```
