# Class Recording — Filtering and Manipulating Detections

## Lesson

**03 — Filtering and Manipulating Detections**

This class covers detection filtering and post-processing using the **Supervision** library together with YOLO.

---

## Topics Covered

During this lesson, we studied:

- `sv.Detections` as a filterable data structure
- Boolean masks
- Confidence filtering
- Class filtering
- Combining multiple filtering conditions
- Excluding specific classes
- Bounding-box area filtering
- Merging multiple detection collections
- Non-Maximum Suppression (NMS)
- NMS threshold comparison
- Sorting detections by confidence
- Selecting Top-N detections
- Bounding-box center calculations
- Spatial filtering
- Filtering detections by image position
