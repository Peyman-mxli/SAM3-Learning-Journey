## Source-Use Notes

- Prefer Meta's official documentation and the official model card for technical claims.
- Confirm runtime commands against current backend documentation before installation.
- Record the artifact name, release, quantization, and runtime used in every experiment.
- Distinguish official capabilities from this repository's proposed SAM 3 integration.
- Do not describe the integration as validated until it has been executed and its outputs have been inspected.
