# Input Assets — Segmentation with SAM 3

This directory contains the original input media used by the practical implementation of **Session 06 — Segmentation with SAM**.

---

## Purpose

Images placed in this directory are used as the source data for the segmentation pipeline.

The practical workflow uses the input image for:

- YOLO object detection
- Bounding-box generation
- SAM 3 bounding-box prompting
- Segmentation-mask generation
- Mask analysis
- Object extraction

---

## Workflow

    Input Image
         ↓
       YOLO
         ↓
    Bounding Boxes
         ↓
       SAM 3
         ↓
    Segmentation Masks

---

## Input Guidelines

Input files stored here should:

- Be supported image formats such as `.jpg`, `.jpeg`, or `.png`
- Remain unchanged during processing
- Be clearly named
- Be suitable for object detection and segmentation experiments

The practical Python script should read the source image from this directory rather than modifying the original file.

---

## Reproducibility

Keeping the original image separate from generated outputs makes the practical easier to reproduce.

Any images, masks, extracted objects, or metadata generated by the pipeline should be saved in the corresponding:

`../output/`

directory.
