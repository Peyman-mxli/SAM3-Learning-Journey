# Assets — Segmentation with SAM 3

This directory contains the media files used and generated by the practical implementation of **Session 06 — Segmentation with SAM**.

The assets are separated into input and output directories to keep original media separate from generated segmentation results.

---

## Directory Structure

    assets/
    ├── README.md
    ├── input/
    └── output/

---

## Input

The `input/` directory contains the original media used by the segmentation pipeline.

These files are used as the source data for:

- YOLO object detection
- Bounding-box generation
- SAM 3 segmentation
- Mask analysis

Original input files should remain unchanged so that experiments can be reproduced consistently.

---

## Output

The `output/` directory contains results generated by the segmentation pipeline.

Depending on the practical execution, outputs may include:

- Segmentation visualizations
- Raw mask visualizations
- Extracted objects
- Detection and segmentation metadata
- JSON files containing encoded masks

Generated files should be stored here rather than mixed with the original input media.

---

## Purpose

Separating input and output assets makes the practical workflow easier to understand and reproduce.

The organization follows this pattern:

    Original Media
          ↓
       input/
          ↓
    YOLO + SAM 3
          ↓
       output/
          ↓
    Segmentation Results

This structure also makes it easier to expand the practical later without modifying the original source files.
