# Output Assets — Segmentation with SAM 3

This directory contains the files generated by the practical implementation of **Session 06 — Segmentation with SAM**.

---

## Purpose

The `output/` directory keeps all generated results separate from the original input media.

Depending on the execution of the practical pipeline, this directory may contain:

- Segmentation visualizations
- Raw segmentation masks
- Extracted objects
- Mask analysis results
- Detection and segmentation metadata
- JSON files containing encoded segmentation masks

---

## Workflow

    Input Image
         ↓
       YOLO
         ↓
    Bounding Boxes
         ↓
       SAM 3
         ↓
    Segmentation Masks
         ↓
    Analysis / Export
         ↓
      output/

---

## Segmentation Results

SAM 3 produces pixel-level masks representing the exact regions associated with detected objects.

These masks can be used to generate visual results or perform additional analysis.

Examples include:

- Visualizing individual masks
- Isolating objects from the background
- Measuring segmented object area
- Comparing mask area with bounding-box area

---

## Stored Mask Data

Segmentation masks can also be stored as structured data.

Because NumPy boolean arrays cannot be written directly to JSON, the practical demonstrates how masks can be:

1. Flattened
2. Packed using `np.packbits`
3. Converted to bytes
4. Encoded using Base64
5. Stored inside JSON

This makes it possible to preserve segmentation results for later use.

---

## Reproducibility

Generated files should be saved in this directory rather than overwriting the original input image.

This keeps the workflow organized as:

    assets/
    ├── input/
    │   └── Original media
    │
    └── output/
        └── Generated results

Keeping input and output data separate makes experiments easier to reproduce, inspect, and document.
