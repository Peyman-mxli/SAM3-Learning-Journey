# Object Tracking — Assets

This directory contains the media assets used by the practical exercises in the **Object Tracking** section of the SAM3 Computer Vision Learning Journey.

The assets provide the input and output files required to demonstrate object tracking, tracking IDs, trajectories, and video-processing workflows.

---

## Purpose

The assets in this directory are used to support practical exercises involving:

- Supervision
- ByteTrack
- OpenCV
- Video processing
- Object detections
- Tracking IDs
- Tracking annotations
- Object trajectories
- Tracking analytics

---

## Directory Structure

```text
assets/
├── README.md
├── input/
│   └── tracking_demo.mp4
└── output/
    └── tracked_demo.mp4
```

---

## Input Assets

The `input/` directory contains the original video used by the practical tracking exercise.

The main input video is:

```text
tracking_demo.mp4
```

The video is approximately **10 seconds long** and contains multiple moving objects designed to demonstrate object-tracking concepts.

The input video is not modified directly.

Instead, the practical script reads the video frame by frame and generates a new annotated output video.

---

## Output Assets

The `output/` directory is used to store videos generated by the practical tracking pipeline.

The expected output video is:

```text
tracked_demo.mp4
```

The processed video can contain:

- Bounding boxes
- Object labels
- Persistent tracking IDs
- Tracking annotations
- Object trajectories
- Tracking information

---

## Practical Workflow

The assets are used in the following workflow:

```text
tracking_demo.mp4
        ↓
Read Video
        ↓
Extract Frames
        ↓
Object Detections
        ↓
sv.Detections
        ↓
Supervision
        ↓
ByteTrack
        ↓
tracker_id
        ↓
Tracking Annotations
        ↓
Object Trajectories
        ↓
Tracking Analytics
        ↓
tracked_demo.mp4
```

---

## Input and Output Separation

Keeping input and output assets in separate directories prevents the original demonstration video from being overwritten.

```text
assets/input/
```

contains the original source material.

```text
assets/output/
```

contains files generated by the practical exercises.

This structure also makes the practical workflow easier to reproduce and maintain.

---

## Synthetic Demonstration Video

The initial `tracking_demo.mp4` asset is a short synthetic demonstration video created specifically for learning object-tracking concepts.

Because the video contains synthetic objects rather than real-world YOLO classes, the first practical exercise focuses on understanding the tracking workflow and ByteTrack behavior without depending on YOLO classification accuracy.

A later exercise can extend the same workflow to a real-world video using:

```text
YOLO
  ↓
sv.Detections
  ↓
ByteTrack
  ↓
tracker_id
```

This separation makes it possible to understand object tracking before introducing additional detection complexity.
