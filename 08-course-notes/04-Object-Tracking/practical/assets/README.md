# Object Tracking — Assets

This directory contains the media assets used by the practical exercises in the **Object Tracking** section of the SAM3 Computer Vision Learning Journey.

---

## Purpose

The assets stored here are used to test and demonstrate object-tracking workflows with:

- Supervision
- ByteTrack
- OpenCV
- Video processing
- Tracking IDs
- Object trajectories
- Tracking annotations
