# Object Tracking — Output Assets

This directory contains the generated output files produced by the practical exercises in the **Object Tracking** section of the SAM3 Computer Vision Learning Journey.

The files stored here are generated after processing the input video through the object-tracking pipeline.

---

## Purpose

The `output/` directory keeps generated tracking results separate from the original input assets.

The practical exercise reads the source video from:

```text
assets/input/tracking_demo.mp4
```

and generates the processed video inside this directory.

---

## Expected Output

The main output video is:

```text
tracked_demo.mp4
```

After running the practical exercise, the directory structure will be:

```text
output/
├── README.md
└── tracked_demo.mp4
```

---

## Output Video

The generated `tracked_demo.mp4` video demonstrates the results of the tracking pipeline.

Depending on the practical exercise, the output can contain:

- Bounding boxes
- Object labels
- Persistent tracking IDs
- `tracker_id` values
- Tracking annotations
- Object trajectories
- Frame information
- Basic tracking analytics

---

## Tracking Pipeline

The output video is generated through the following workflow:

```text
tracking_demo.mp4
        ↓
Read Video Frames
        ↓
Object Detections
        ↓
sv.Detections
        ↓
Supervision
        ↓
ByteTrack
        ↓
tracker_id
        ↓
Tracking Annotations
        ↓
Object Trajectories
        ↓
Tracking Analytics
        ↓
tracked_demo.mp4
```

## Input and Output

The original video remains inside:

```text
assets/input/
```

The generated tracking result is stored inside:

```text
assets/output/
```

This gives the practical exercise a clear separation between source material and generated results:

```text
assets/
├── input/
│   ├── README.md
│   └── tracking_demo.mp4
│
└── output/
    ├── README.md
    └── tracked_demo.mp4
```

---

## Generated Files

Files inside this directory should normally be considered generated results.

The practical Python script will create or overwrite:

```text
tracked_demo.mp4
```

when the tracking pipeline is executed.

This allows the practical exercise to be repeated without modifying the original source video.

---

## Practical Script

The output will be generated by:

```text
practical/object_tracking_practical.py
```

The script will:

1. Open the input video.
2. Read the video frame by frame.
3. Create object detections.
4. Convert the detections into `sv.Detections`.
5. Pass detections through ByteTrack.
6. Retrieve persistent `tracker_id` values.
7. Annotate tracked objects.
8. Visualize object trajectories.
9. Write the processed frames to the output video.

---

## Expected Result

The final result demonstrates the transition from independent detections to persistent object tracking:

```text
Detection
    ↓
Object Association
    ↓
Persistent tracker_id
    ↓
Tracking Visualization
    ↓
Tracking Analytics
```

The resulting video makes it possible to visually inspect whether object identities remain consistent across consecutive frames.
