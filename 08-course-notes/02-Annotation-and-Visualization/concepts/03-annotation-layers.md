# Annotation Layers

## Overview

One of the most useful features of Supervision is the ability to combine multiple Annotators on the same image.

Instead of choosing only one visualization method, several Annotators can be applied sequentially.

Each Annotator adds another visual layer to the image.

---

## What Is an Annotation Layer?

An annotation layer is a visual element added to an image to represent detection information.

Examples include:

- Bounding boxes
- Ellipses
- Detection points
- Class labels
- Confidence scores

A single detection can therefore have multiple visual representations.

---

## Layered Visualization

A visualization pipeline may look like:

```text
Original Image
      ↓
Bounding Boxes
      ↓
Ellipses
      ↓
Detection Points
      ↓
Labels
      ↓
Final Visualization
```

In Supervision, these layers can be created using:

```text
BoxAnnotator
EllipseAnnotator
DotAnnotator
LabelAnnotator
```

---

## Creating the Annotators

First, the Annotator objects are created.

```python
box_annotator = sv.BoxAnnotator(
    color=sv.ColorPalette.DEFAULT,
    thickness=3
)

ellipse_annotator = sv.EllipseAnnotator()

dot_annotator = sv.DotAnnotator()

label_annotator = sv.LabelAnnotator(
    text_scale=0.6
)
```

Each Annotator has a different visualization responsibility.

---

## Layer 1 — Bounding Boxes

The first layer can be created using `BoxAnnotator`.

```python
annotated_image = box_annotator.annotate(
    scene=image.copy(),
    detections=detections
)
```

Notice that the pipeline starts with:

```python
image.copy()
```

This creates a copy of the original image before annotations are added.

---

## Layer 2 — Ellipses

The result from the first layer is passed to the next Annotator.

```python
annotated_image = ellipse_annotator.annotate(
    scene=annotated_image,
    detections=detections
)
```

The image now contains both:

```text
Bounding Boxes
+
Ellipses
```

---

## Layer 3 — Detection Points

The next layer uses `DotAnnotator`.

```python
annotated_image = dot_annotator.annotate(
    scene=annotated_image,
    detections=detections
)
```

The visualization now contains:

```text
Bounding Boxes
+
Ellipses
+
Detection Points
```

---

## Layer 4 — Labels

Finally, labels are added.

```python
annotated_image = label_annotator.annotate(
    scene=annotated_image,
    detections=detections,
    labels=labels
)
```

The final image contains all visualization layers.

```text
Bounding Boxes
+
Ellipses
+
Detection Points
+
Labels
```

---

## Complete Layer Pipeline

The complete sequence can be represented as:

```text
image.copy()
     ↓
BoxAnnotator
     ↓
annotated_image
     ↓
EllipseAnnotator
     ↓
annotated_image
     ↓
DotAnnotator
     ↓
annotated_image
     ↓
LabelAnnotator
     ↓
Final annotated_image
```

---

## Why the Same Variable Is Reused

The variable:

```python
annotated_image
```

is reused throughout the pipeline.

Each Annotator receives the result generated by the previous Annotator.

Conceptually:

```text
Image Version 1
      ↓
Add Layer
      ↓
Image Version 2
      ↓
Add Layer
      ↓
Image Version 3
```

This allows multiple visual elements to accumulate on the same image.

---

## Why Layer Order Matters

Annotators draw visual elements on top of the current image.

Therefore, the order in which they are applied can affect the final appearance.

For example:

```text
Boxes
  ↓
Ellipses
  ↓
Dots
  ↓
Labels
```

places labels near the end of the pipeline.

This helps keep textual information visible after the other visual elements have been drawn.

---

## Detection Data Does Not Change

The important concept is that the visualization changes, but the underlying detection data remains the same.

```text
                ┌─ BoxAnnotator
                │
sv.Detections ──┼─ EllipseAnnotator
                │
                ├─ DotAnnotator
                │
                └─ LabelAnnotator
```

All of these Annotators can use the same:

```python
detections
```

object.

The Annotators change the image visualization, not the YOLO prediction itself.

---

## Reusable Pipeline Design

Layered annotation makes it possible to build reusable visualization pipelines.

```text
Input
  ↓
Object Detection
  ↓
Structured Detections
  ↓
Visualization Layers
  ↓
Output
```

Individual layers can be added, removed, reordered, or customized without changing the detection stage.

---

## Key Takeaway

Annotation layers allow multiple visualization techniques to be composed on top of the same detection results.

The fundamental idea is:

```text
One Detection Result
        ↓
Multiple Visualization Layers
        ↓
One Final Annotated Image
```

This separation between **detection data** and **visualization layers** makes computer vision pipelines more flexible, reusable, and easier to customize.
