---

# Video Resolution

The practical reads video information using:

```python
video_info = sv.VideoInfo.from_video_path(
    INPUT_VIDEO
)
```

The resolution can then be inspected with:

```python
print(
    f"Resolution: "
    f"{video_info.width} x {video_info.height}"
)
```

These dimensions are used when defining the zones.

---

# Relative Zone Coordinates

Instead of using only fixed coordinates, the practical can define regions relative to the video size.

For example:

```python
video_info.width // 2
```

represents half of the frame width.

And:

```python
video_info.height // 2
```

represents half of the frame height.

This allows the practical to define zones such as:

```text
Lower-left area
Lower-right area
Top half
Bottom half
```

based on the actual video dimensions.

# GitHub Considerations

Video files can be much larger than source-code and Markdown files.

Before committing generated videos, check their size.

If a generated video is too large for normal GitHub storage, alternatives include:

- Keeping only a shorter demonstration clip
- Compressing the video
- Linking to an externally hosted demonstration
- Documenting how to reproduce the output locally or in Google Colab

The source code and documentation should remain sufficient to reproduce the experiment.
