# Supervision Concepts

This directory contains the theoretical concepts covered during the **Introduction to Supervision** session of the SAM3 course.

## Concepts

- Supervision library
- Computer vision pipelines
- YOLO object detection
- COCO dataset
- Bounding boxes
- XYXY coordinates
- Confidence scores
- Class IDs and class names
- `sv.Detections`
- Detection filtering
- Bounding box annotation
- Label annotation

These concepts provide the foundation for building structured and reusable computer vision pipelines using **Ultralytics YOLO, OpenCV, and Supervision**.
