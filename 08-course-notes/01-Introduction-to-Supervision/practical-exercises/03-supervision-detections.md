# Exercise 03 — Converting YOLO Results to `sv.Detections`

## Objective

The objective of this exercise is to convert the predictions generated by YOLO into the standardized Supervision data structure:

```python
sv.Detections
```

We will learn how to:

- Convert Ultralytics results to Supervision.
- Count detected objects.
- Inspect bounding boxes.
- Inspect confidence scores.
- Inspect class IDs.
- Translate class IDs into class names.
- Inspect an individual detection.

---

## 1. Import Supervision

First, import Supervision:

```python
import supervision as sv
```

The standard alias used for Supervision is:

```python
sv
```

---

## 2. Starting with YOLO Results

From the previous exercise, we already have:

```python
results = model(image)[0]
```

At this point:

```text
Image
  ↓
YOLO
  ↓
Ultralytics Result
```

The result is still represented using the Ultralytics format.

---

## 3. Convert to `sv.Detections`

Now perform one of the most important operations in this lesson:

```python
detections = sv.Detections.from_ultralytics(
    results
)
```

The pipeline becomes:

```text
Image
  ↓
YOLO
  ↓
Ultralytics Result
  ↓
sv.Detections.from_ultralytics()
  ↓
sv.Detections
```

Supervision now gives us a standardized representation of the detected objects.

---

## 4. Count the Detected Objects

We can determine how many objects were detected using:

```python
len(detections)
```

Example:

```python
print(
    f"Number of detected objects: "
    f"{len(detections)}"
)
```

Each element inside `detections` represents one detected object.

---

## 5. Inspect Bounding Boxes

Bounding-box coordinates are available through:

```python
detections.xyxy
```

Display them:

```python
print(detections.xyxy)
```

Each row follows:

```text
[x1, y1, x2, y2]
```

Where:

```text
x1 → left
y1 → top
x2 → right
y2 → bottom
```

Conceptually:

```text
detections.xyxy

[
    [x1, y1, x2, y2],
    [x1, y1, x2, y2],
    [x1, y1, x2, y2]
]
```

Each row corresponds to one detected object.

---

## 6. Inspect Confidence Scores

Confidence values are stored in:

```python
detections.confidence
```

Display them:

```python
print(detections.confidence)
```

Example:

```text
[0.94, 0.91, 0.87]
```

These values represent how confident YOLO is about each prediction.

```text
0.94 → 94%
0.91 → 91%
0.87 → 87%
```

---

## 7. Inspect Class IDs

The detected object categories are represented numerically:

```python
detections.class_id
```

Display them:

```python
print(detections.class_id)
```

Example:

```text
[0, 0, 5]
```

For the COCO classes used in this lesson:

```text
0 → person
2 → car
5 → bus
7 → truck
```

---

## 8. Translate Class IDs to Names

YOLO provides the class-name mapping through:

```python
results.names
```

We can display the detected classes:

```python
for class_id in sorted(
    set(detections.class_id)
):
    print(
        f"Class {class_id}: "
        f"{results.names[class_id]}"
    )
```

The relationship is:

```text
detections.class_id
        ↓
Numerical Class
        ↓
results.names
        ↓
Object Name
```

---

## 9. Inspect the First Detection

Supervision allows us to select an individual detection:

```python
first = detections[0]
```

The variable `first` is still an `sv.Detections` object, but it contains only one detection.

---

## 10. Extract its Bounding Box

```python
x1, y1, x2, y2 = first.xyxy[0]
```

Now we can inspect the position:

```python
print(
    f"Position: "
    f"({x1:.0f}, {y1:.0f}) "
    f"to ({x2:.0f}, {y2:.0f})"
)
```

---

## 11. Inspect Class and Confidence

Display the detected class:

```python
print(
    f"Class: "
    f"{results.names[first.class_id[0]]}"
)
```

Display the confidence:

```python
print(
    f"Confidence: "
    f"{first.confidence[0]:.1%}"
)
```

---

## 12. Calculate Bounding-Box Size

Calculate the width:

```python
width = x2 - x1
```

Calculate the height:

```python
height = y2 - y1
```

Then display both:

```python
print(
    f"Size: "
    f"{width:.0f}px wide × "
    f"{height:.0f}px high"
)
```

---

## 13. Complete Exercise

```python
import supervision as sv

# Convert YOLO result to Supervision
detections = sv.Detections.from_ultralytics(
    results
)

# Number of objects
print(
    "Detected objects:",
    len(detections)
)

# Bounding boxes
print("\nBounding boxes:")
print(detections.xyxy)

# Confidence scores
print("\nConfidence:")
print(detections.confidence)

# Class IDs
print("\nClass IDs:")
print(detections.class_id)

# Class names
print("\nDetected classes:")

for class_id in sorted(
    set(detections.class_id)
):
    print(
        f"{class_id}: "
        f"{results.names[class_id]}"
    )

# Inspect first detection
first = detections[0]

x1, y1, x2, y2 = first.xyxy[0]

print("\nFirst detection:")
print(
    "Class:",
    results.names[first.class_id[0]]
)
print(
    f"Confidence: "
    f"{first.confidence[0]:.1%}"
)
print(
    f"Position: "
    f"({x1:.0f}, {y1:.0f}) → "
    f"({x2:.0f}, {y2:.0f})"
)
print(
    f"Size: "
    f"{x2-x1:.0f}px × "
    f"{y2-y1:.0f}px"
)
```

---

## 14. Detection Structure

After conversion, we can think of the data as:

```text
sv.Detections
      │
      ├── xyxy
      │     └── WHERE?
      │
      ├── confidence
      │     └── HOW SURE?
      │
      └── class_id
            └── WHAT?
```

---

## Key Takeaways

The most important operation in this exercise is:

```python
detections = sv.Detections.from_ultralytics(
    results
)
```

And the three properties to remember are:

```python
detections.xyxy
detections.confidence
detections.class_id
```

Together:

```text
xyxy       → WHERE is the object?
confidence → HOW SURE is the model?
class_id   → WHAT object was detected?
```

This standardized representation will now allow us to experiment with confidence thresholds and annotations.
