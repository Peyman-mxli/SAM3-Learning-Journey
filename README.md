# ✨ Overview

This repository documents my learning journey through the **SAM3: Computer Vision with Segment Anything Model 3** course developed by **Meta**, **CENTRO**, and **INFOTEC**.

Its purpose is to provide a complete, step-by-step guide for setting up the development environment required throughout the course, including Google Colab, NVIDIA T4 GPU, Hugging Face, Roboflow, and other essential tools.

In addition to documenting my own progress, this repository is intended to help other students successfully configure their environments and better understand the technologies, concepts, and workflows used throughout the program.

The repository has expanded beyond environment setup and now includes practical Computer Vision projects involving detection, filtering, annotation, video processing, object tracking, segmentation, analytics, visualization, and data persistence.

---

# 🎯 Objectives

- Learn the fundamentals of Computer Vision.
- Understand how Segment Anything Model 3 (SAM3) works.
- Build practical AI projects using real-world images and video.
- Learn to use Google Colab efficiently.
- Configure and use NVIDIA T4 GPU acceleration.
- Work with Hugging Face and Roboflow.
- Learn object detection and visualization workflows.
- Implement detection filtering and Non-Maximum Suppression.
- Process and analyze video.
- Implement persistent object tracking.
- Work with ByteTrack.
- Integrate SAM3 into image and video workflows.
- Generate analytics from Computer Vision results.
- Store structured tracking information using databases.
- Create professional technical documentation.
- Maintain a structured AI and Computer Vision portfolio.
- Share knowledge with other students and developers.

---

# 💡 Why It Matters

Modern Artificial Intelligence and Computer Vision models require specialized development environments, libraries, hardware acceleration, and data-processing workflows that can be difficult for beginners to configure.

This repository simplifies that process by documenting each important step, allowing students to spend more time learning Computer Vision instead of repeatedly solving environment and installation problems.

It also serves as a personal technical knowledge base where concepts learned during the course are transformed into documented examples and practical projects.

By combining theory, implementation, experimentation, troubleshooting, and project development, the repository demonstrates the progression from fundamental Computer Vision concepts toward complete visual analysis systems.
