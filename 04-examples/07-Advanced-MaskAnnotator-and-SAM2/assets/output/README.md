File:

```text
04_person_only_segmentation_output.png
```

Generated by:

[`../../04_person_only_segmentation.py`](../../04_person_only_segmentation.py)

This example filters YOLO detections **before** running SAM 3.

Validated detection results:

```text
Total YOLO detections: 6
Person detections: 4
Objects removed before SAM: 2
```

Only the four person bounding boxes were passed to SAM 3.

Validated segmentation result:

```text
Person masks generated: 4
```

Workflow:

```text
bus.jpg
   ↓
YOLOv8
   ↓
6 Detections
   ↓
Filter class_id == 0
   ↓
4 Person Detections
   ↓
SAM 3
   ↓
4 Person Masks
   ↓
MaskAnnotator + BoxAnnotator
   ↓
04_person_only_segmentation_output.png
```

The key concept demonstrated by this output is:

```text
Detect Everything
      ↓
Filter Relevant Objects
      ↓
Segment Only Those Objects
```

instead of:

```text
Detect Everything
      ↓
Segment Everything
      ↓
Discard Unwanted Results
```
