# Input Assets — SAM3 Text Prompts

This directory contains the input images used by the Session 08 examples.

```text
bus.jpg
zidane.jpg
```

`bus.jpg` is the validated primary input for all six text-prompt examples. `zidane.jpg` is retained as a secondary course image for future reusable-prompt experiments.

The images are stored in the repository so the examples do not need to download inputs at runtime.
