# Introduction to Supervision — Examples

Practical code examples from the **Introduction to Supervision** session of the SAM3 course.

These examples demonstrate the main computer vision workflow covered during the session:

- Loading images with OpenCV
- Running YOLO object detection
- Converting YOLO results to `sv.Detections`
- Working with bounding boxes
- Inspecting confidence scores
- Filtering detections
- Annotating images with Supervision
- Comparing YOLO models
- Testing the pipeline with custom images
