# Agentic AI Programming — Code Examples

This directory contains runnable Python examples based on the **Agentic AI Programming Methodologies** session of the SAM3 course.

The examples focus on two core ideas introduced during the class:

1. Using AI-assisted prompts to generate computer vision code.
2. Using AI to debug, analyze, and improve existing code.

## Examples

### 01 — AI-Generated Image Processing Function

A Python function that:

- Receives an image URL
- Downloads the image
- Loads it with OpenCV
- Converts it to grayscale
- Returns the processed image

File:

`01-ai-generated-function.py`

### 02 — OpenCV Debugging Example

A small OpenCV example designed to demonstrate the workflow:

```text
Generate Code
    ↓
Run Code
    ↓
Read Error
    ↓
Provide Error to AI
    ↓
Understand the Problem
    ↓
Fix the Code

Run Again
