## Google Drive Notebook Collection

The Drive folder is the canonical course collection of sixteen notebooks. Access can depend on the sharing configuration and the Google account currently signed in.

Recommended workflow:

1. Open the folder using the course-authorized account.
2. Preserve the original notebook filename.
3. Make a personal copy before editing.
4. Record which session the notebook belongs to.
5. Keep raw course notebooks separate from improved practical implementations.
6. Export completed notebooks with their outputs when execution evidence matters.

This repository follows that separation: original notebooks are retained as course artifacts, while professional scripts, documentation, and outputs are organized around them.

## Calendar Download

The `.ics` file can be imported into Google Calendar, Outlook, Apple Calendar, and other calendar clients.

Download:

```bash
curl -L \
  "https://sam-3-vision-computacional.vercel.app/SAM3-agosto-2026.ics" \
  -o SAM3-agosto-2026.ics
```

Before importing:

- Confirm the timezone.
- Review whether the calendar creates a new calendar or merges into an existing one.
- Check meeting links against current course announcements.
- Avoid repeated imports that create duplicate events.

An ICS file is a snapshot. Schedule or meeting-link changes may be announced separately.

## Glossary

The course glossary is useful for reviewing concepts before a lesson and for keeping terminology consistent in reports.

Recommended study pattern:

```text
Read lesson objective
        ↓
Review unfamiliar glossary terms
        ↓
Run notebook
        ↓
Return to glossary with practical context
        ↓
Write personal explanation and example
```

The repository's resource guides extend glossary definitions with installation instructions, code, troubleshooting, and course-specific examples.

## Link and File Safety

- Confirm that the domain matches the official course site before entering credentials.
- Do not publish private Zoom links or personal access information.
- Do not commit Google or Hugging Face tokens.
- Treat externally hosted files as potentially changeable.
- Record source URL and download date for important artifacts.
- Scan downloaded executable or archive files before opening them.
- Preserve original files before making edits.

## If a Link Stops Working

1. Check the official course homepage.
2. Check course email or announcements for a replacement.
3. Confirm that the correct account is signed in.
4. Record the broken URL and date.
5. Update the repository only after confirming the authoritative replacement.

Do not replace an official course link with an unverified mirror.
