# ⚙️ Setup

Welcome to the setup section of the **SAM3 Learning Journey** repository.

This folder contains all installation guides and environment configuration required before starting the course.

The goal is to prepare a complete AI development environment that works correctly throughout the entire learning journey.

---

# 📦 What You Will Configure

During this section you will learn how to install and configure:

- Git
- GitHub
- Google Colab
- NVIDIA T4 GPU
- Hugging Face
- Roboflow
- Python
- Jupyter Notebook
- VS Code
- Required Python Libraries

---

# 📚 Contents

This folder will gradually include step-by-step guides for every setup task.


---

# 🎯 Objective

By completing every guide inside this folder you will have a fully configured environment ready for the SAM3 course.

No previous experience is required.

Every guide is written for complete beginners.
