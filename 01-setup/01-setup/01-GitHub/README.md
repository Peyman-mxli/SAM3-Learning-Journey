# ✨ Overview

GitHub is the world's largest platform for hosting, managing, and collaborating on software projects. Built on top of Git, it provides developers with a centralized environment to store source code, document projects, track changes, collaborate with teams, and publish software to the world.

Today, GitHub is used by millions of developers, researchers, universities, startups, and some of the world's largest technology companies, including Microsoft, Google, Meta, NVIDIA, Amazon, and OpenAI.

For this course, GitHub will become your digital portfolio. Every notebook, project, document, screenshot, and experiment will be organized inside professional repositories, allowing you to track your progress and showcase your skills.

---

# 📖 History of GitHub

GitHub was founded in **2008** by **Tom Preston-Werner**, **Chris Wanstrath**, **PJ Hyett**, and **Scott Chacon**.

The platform was created to simplify software collaboration using Git, making version control easier for developers around the world.

In **2018**, Microsoft acquired GitHub for **7.5 billion USD**, strengthening its commitment to developers and open-source software while continuing to support one of the largest software communities in the world.

Today, GitHub hosts hundreds of millions of repositories and has become one of the most important tools in modern software engineering.

# 💡 Why GitHub Matters

GitHub is much more than a website for storing code.

It has become the standard platform for collaboration, documentation, version control, and open-source development.

Software engineers use GitHub every day to:

- Store source code securely.
- Track every change made to a project.
- Collaborate with developers worldwide.
- Document applications professionally.
- Review code before publishing.
- Build public portfolios.
- Contribute to open-source software.
- Showcase technical skills to recruiters and employers.

For students, GitHub provides an opportunity to demonstrate practical knowledge instead of simply listing skills on a résumé. A well-documented GitHub repository allows employers to evaluate how you organize projects, write documentation, and solve technical problems.
