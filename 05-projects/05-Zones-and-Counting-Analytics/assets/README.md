# Assets — Zones and Counting Analytics

This directory contains the input and output media files used by the **Zones and Counting Analytics** project.

The project processes a traffic video using:

- YOLOv8 object detection
- Supervision
- ByteTrack object tracking
- PolygonZone occupancy analysis
- LineZone crossing analysis

---

## Directory Structure

```text
assets/
│
├── README.md
│
├── input/
│   ├── README.md
│   └── vehicles.mp4
│
└── output/
    └── README.md
```

---

## Input Assets

The `input/` directory contains the original media used by the computer vision pipeline.

```text
assets/input/
```

The main input video is:

```text
vehicles.mp4
```

This traffic video contains vehicles moving along a highway and is used to demonstrate:

- Object detection
- Object tracking
- Persistent tracker IDs
- Polygon occupancy
- Virtual line crossings
- Directional counting

---

## Output Assets

The `output/` directory stores media generated by the project.

```text
assets/output/
```

The main expected output is:

```text
zones_counting_analytics.mp4
```

The processed video visualizes:

- Tracked objects
- Bounding boxes
- Tracker IDs
- PolygonZone
- Current zone occupancy
- LineZone
- Crossing counters

---

## Asset Workflow

```text
assets/input/vehicles.mp4
          ↓
YOLOv8
          ↓
Object Detections
          ↓
ByteTrack
          ↓
Tracked Objects
          ↓
PolygonZone + LineZone
          ↓
Spatial Analytics
          ↓
Annotation
          ↓
assets/output/zones_counting_analytics.mp4
```

---

## Input vs. Output

```text
INPUT
Original traffic video
        ↓
Computer Vision Pipeline
        ↓
OUTPUT
Annotated spatial analytics video
```

The original input file should remain unchanged.

All generated media should be stored inside:

```text
assets/output/
```
