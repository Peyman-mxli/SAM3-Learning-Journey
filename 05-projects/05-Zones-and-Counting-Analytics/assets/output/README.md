# Output Assets — Zones and Counting Analytics

This directory contains the processed video files generated by the **Zones and Counting Analytics** project.

The output files are created after processing the source traffic video with YOLOv8, ByteTrack, PolygonZone, and LineZone.

## Output Content

The generated video visualizes the complete spatial analytics pipeline.

It may contain:

- YOLOv8 object detections
- Bounding boxes
- Object class information
- Persistent tracker IDs
- PolygonZone boundary
- Current PolygonZone occupancy
- LineZone boundary
- Directional crossing counters
- Spatial analytics information

## PolygonZone Output

The PolygonZone component visualizes a defined region of interest.

It provides:

```python
polygon_zone.current_count
```

This value represents the number of tracked objects currently located inside the polygon.

Conceptually:

```text
Tracked Objects
      ↓
PolygonZone
      ↓
Objects Inside Area
      ↓
Current Occupancy
```

---

## LineZone Output

The LineZone component visualizes a virtual counting boundary.

It maintains:

```python
line_zone.in_count
line_zone.out_count
```

These counters represent accumulated directional crossing events.

Conceptually:

```text
Tracked Object
      ↓
Crosses Virtual Line
      ↓
LineZone
      ↓
Directional Event
      ↓
Counter Updated
```

---

## Occupancy vs. Flow

The output video demonstrates two different types of spatial analytics.

### Occupancy

Measured using:

```text
PolygonZone
```

Question:

```text
How many objects are inside this area right now?
```

### Flow

Measured using:

```text
LineZone
```

Question:

```text
How many objects have crossed this boundary?
```

The combined output therefore provides:

```text
Occupancy + Flow
        ↓
Spatial Video Analytics
```

## Browser Compatibility

Depending on the video codec generated by OpenCV or Supervision, the output may need to be converted to H.264 for reliable playback in:

- GitHub
- Google Colab
- Web browsers
- HTML video players

FFmpeg can be used when conversion is necessary.

Example:

```bash
ffmpeg \
-i assets/output/zones_counting_analytics.mp4 \
-vcodec libx264 \
-crf 28 \
-preset fast \
-an \
assets/output/zones_counting_analytics_h264.mp4
```

## GitHub File Size

Video files can become large.

Before uploading an output video to GitHub, check its size.

GitHub's web upload interface may reject large files.

A compressed version can be generated when necessary while keeping the original project workflow unchanged.

Example output:

