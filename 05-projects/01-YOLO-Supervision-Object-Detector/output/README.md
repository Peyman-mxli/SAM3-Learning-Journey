# Output Files

This folder stores the results generated by the YOLO + Supervision Object Detector.

After running:

```text
object_detector.py
the project will generate:

output/
├── annotated_image.jpg
└── predictions.json
annotated_image.jpg

This is the original input image with YOLO detections drawn on top of it.

It may contain:

Bounding boxes
Object class names
Confidence scores

Example:

person 94%
car 91%
bus 96%
dog 88%
predictions.json

This file stores the same detection information as structured data.

For each detected object, it contains:

Class ID
Class Name
Confidence Score
Bounding Box Coordinates

Example:

{
  "class_id": 0,
  "class_name": "person",
  "confidence": 0.94,
  "bounding_box": {
    "x1": 100.0,
    "y1": 50.0,
    "x2": 400.0,
    "y2": 500.0
  }
}
Project Flow
input/image.png
      ↓
object_detector.py
      ↓
YOLO + Supervision
      ↓
output/annotated_image.jpg
      +
output/predictions.json

The output folder therefore contains the final visual and data results produced by the project.


After this, the folder structure is ready and we can move to **actually running the project**.
