# Input Images

Place the image you want to analyze in this folder.

The default project configuration expects:

```text
input/image.jpg
```

The file `image.jpg` will be the image analyzed by the YOLO object detection model.

For example, the image could contain:

- People
- Cars
- Buses
- Animals
- Street scenes
- Indoor objects

YOLO will analyze the image and try to identify the objects it recognizes.

The results will later be saved inside the `output/` folder.
