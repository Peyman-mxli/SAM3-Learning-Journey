# Project 13 — Visual Tracking and Analysis Laboratory

A portfolio-focused implementation of the **SAM 3 Computer Vision Laboratory** proposal generated by the CENTRO × INFOTEC project engine.

## Project origin

**Laboratory proposal:** Sistema de Seguimiento y Análisis Visual  
**Run:** `45ef3e05`

The laboratory proposed a Python system capable of detecting, segmenting, tracking, storing, comparing, and analyzing objects or people across recorded images and videos.

This project turns that proposal into a reproducible engineering structure.

## Objective

Build an application that can:

- load recorded images or videos while preserving source metadata;
- detect objects with YOLO;
- assign temporal identities with ByteTrack;
- segment selected detections with SAM 3;
- persist observations in SQLite;
- compare historical sessions;
- calculate tracking and evaluation metrics;
- export structured evidence;
- expose the results through an analytical dashboard;
- document failure cases such as illumination, scale, occlusion, and out-of-distribution data.

## MVP contract

### Included

- Load a recorded image or video.
- Preserve date and source.
- Store identifier, timestamp, medium, result, confidence, and notes.
- Query previous observations.
- Compare multiple sessions.
- Display evidence in a digital analysis interface.
- Document failure modes.

### Not part of the first MVP

- Live capture.
- Automated threshold alerts before metrics and false-positive behavior are validated.

## Definition of done

The project is considered complete when it can:

1. process recorded video;
2. retain tracking history in a database;
3. generate exportable performance reports;
4. compare sessions;
5. show visual and structured evidence;
6. document known limitations.

## Relationship to Project 06

Project 06 provided the earlier practical experimentation and verified tracking/analytics evidence. Project 13 is intentionally separate: it is structured around the **official laboratory proposal** and presents the work as a dedicated portfolio project.

Project 06 should be treated as prior experimental evidence, not as a substitute for this project.
