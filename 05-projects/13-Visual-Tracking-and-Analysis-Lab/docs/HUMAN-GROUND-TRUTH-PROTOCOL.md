# Project 13 — Human Ground-Truth Protocol

This document defines the final evidence layer for temporal identity and
segmentation metrics.

## Why this exists

Model predictions are not ground truth. Permission to modify the repository
does not make automatically generated labels human-reviewed evidence.

Project 13 therefore separates:

1. **candidate annotations** generated by YOLO + ByteTrack;
2. **reviewed reference annotations** corrected and accepted by a reviewer;
3. **metrics** calculated only after review.

## Tracking ground truth

Generate a review packet:

```bash
python evaluation/generate_ground_truth_review_packet.py \
  data/input/tracking_test_01.mp4 \
  --every 5 \
  --max-frames 15
```

Open the review interface:

```bash
streamlit run evaluation/ground_truth_review_app.py
```

For each candidate row:

- confirm the class;
- confirm/correct the box;
- keep the same `review_track_id` for the same real entity across frames;
- reject false positives;
- add missed entities if necessary;
- mark the row `reviewed=true`.

Finalize:

```bash
python evaluation/finalize_tracking_ground_truth.py \
  --require-all-reviewed
```

Then evaluate:

```bash
python evaluation/evaluate_tracking_csv.py \
  <prediction_csv> \
  evaluation/tracking_ground_truth.csv \
  --output results/tracking_evaluation.json
```

## Segmentation ground truth

Pixel-level segmentation requires independently reviewed masks. The existing
`evaluate_segmentation_masks.py` tool is ready to calculate Mask IoU and
Dice once those reference masks exist.

A model-produced SAM 3 mask must **not** be reused as its own ground truth.

## Evidence integrity rule

Project 13 may report:

- detection Precision / Recall / F1 from reviewed boxes;
- environmental robustness indicators from controlled experiments;
- ID-switch / fragmentation accuracy only from reviewed temporal IDs;
- Mask IoU / Dice only from independently reviewed reference masks.

This protects the portfolio from circular evaluation and fabricated metrics.
