# Segmentation Masks

This directory contains representative pixel-level segmentation masks generated by **SAM 3** for Project 07.

The selected masks correspond directly to the representative objects stored inside:

    ../extracted_objects/

---

## Selected Masks

- `object_00_mask.png`
- `object_01_mask.png`
- `object_02_mask.png`
- `object_04_mask.png`
- `object_05_mask.png`
- `object_17_mask.png`

Each mask represents the pixels assigned to a detected object by SAM 3.

    White pixels → segmented object
    Black pixels → background

These masks provide visual evidence of the pixel-level segmentation stage of the pipeline.

---

## Relationship to Extracted Objects

Each selected mask has a corresponding extracted object:

    object_00_mask.png → object_00.png
    object_01_mask.png → object_01.png
    object_02_mask.png → object_02.png
    object_04_mask.png → object_04.png
    object_05_mask.png → object_05.png
    object_17_mask.png → object_17.png

The mask determines which pixels from the original image are preserved during object extraction.

Conceptually:

    Original Image
          +
    SAM 3 Mask
          ↓
    Pixel Selection
          ↓
    Extracted Object

---

## Purpose

Keeping representative masks in the repository makes it possible to inspect the segmentation results without storing every generated mask.

The complete Project 07 execution generated 25 segmentation masks. This directory preserves a representative subset covering different objects, positions, and scales.
