# Output Assets — Project 07 SAM 3 Segmentation Pipeline

This directory contains the files generated by **Project 07 — SAM 3 Segmentation Pipeline**.

The output directory keeps generated segmentation results separate from the original source images stored inside `assets/input/`.

---

## Purpose

The pipeline generates multiple types of Computer Vision results from each processed image.

These outputs provide visual and structured evidence of:

- YOLOv8 object detection
- Confidence filtering
- SAM 3 segmentation
- Pixel-level masks
- Object extraction
- Mask-area analysis
- Bounding-box comparison
- Final visualization
- Structured result export

---

After running the completed project, this directory may contain:

## Annotated Segmentation

The file:

    annotated_segmentation.png

represents the final visualization produced by the complete pipeline.

It may contain:

- SAM 3 segmentation masks
- YOLO bounding boxes
- Object labels
- Confidence scores
- Object indices

This provides a single visual summary of the detected and segmented objects.

---

## Segmentation Masks

Individual masks are stored inside:

    masks/

Each mask represents the pixel-level region predicted by SAM 3 for one detected object.

Example:

    object_00_mask.png

A mask visually represents:

    White pixels → segmented object
    Black pixels → background

Internally, SAM 3 masks are represented as boolean NumPy arrays:

    True  → object pixel
    False → background pixel

---

## Extracted Objects

Individual segmented objects are stored inside:

    extracted_objects/

For each object, pixels outside the segmentation mask are removed from the original image.

Conceptually:

    Original Image
          ↓
    SAM 3 Mask
          ↓
    Background Removal
          ↓
    Extracted Object

The main NumPy operation is:

    object_image[~mask] = 0

This produces a pixel-level extraction rather than a rectangular bounding-box crop.

---

## Structured Results

The file:

    segmentation_results.json

stores structured information generated by the pipeline.

The data may include:

- Input filename
- Image dimensions
- Number of YOLO detections
- Number of accepted detections
- Number of SAM 3 masks
- Object indices
- Class IDs
- Class names
- Confidence scores
- Bounding-box coordinates
- Bounding-box areas
- Segmentation-mask areas
- Image coverage percentages
- Mask-to-box percentages
- Generated output filenames

This makes the segmentation results available for later analysis without requiring the Computer Vision models to be executed again.

---

## Mask Area Analysis

For every segmented object, the pipeline measures:

    Mask Area

and compares it with:

    Bounding-Box Area

The percentage is calculated conceptually as:

    Mask Area
    ───────────────── × 100
    Bounding-Box Area

This helps quantify how much of the rectangular YOLO detection is actually occupied by the segmented object.

## Reproducibility

Generated files should always be stored in this directory rather than replacing files inside:

    ../input/

Keeping source and generated media separate makes it easier to:

- Repeat experiments
- Compare model results
- Inspect segmentation quality
- Debug the pipeline
- Preserve original images
- Document project results
