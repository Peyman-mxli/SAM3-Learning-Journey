# Assets — Project 07 SAM 3 Segmentation Pipeline

This directory contains the input media and generated output files used by **Project 07 — SAM 3 Segmentation Pipeline**.

The assets are separated into dedicated input and output directories so that original source media remains separate from generated segmentation results.

---

## Directory Structure

    assets/
    ├── README.md
    ├── input/
    └── output/

---

## Input

The `input/` directory contains the original image files used by the segmentation pipeline.

Input media may be used for:

- YOLOv8 object detection
- Confidence filtering
- Bounding-box generation
- SAM 3 prompting
- Pixel-level segmentation
- Mask analysis
- Object extraction
- Visualization

The original input files should remain unchanged during processing.

---

## Output

The `output/` directory contains files generated by the project.

Expected generated results may include:

- Annotated segmentation images
- Individual segmentation masks
- Extracted segmented objects
- Structured JSON results
- Analysis summaries

Generated files should be stored here instead of modifying or overwriting the original input media.

---

## Workflow

    Original Image
         ↓
       input/
         ↓
    YOLOv8 Detection
         ↓
    Confidence Filtering
         ↓
    Bounding Boxes
         ↓
       SAM 3
         ↓
    Segmentation Masks
         ↓
    Analysis / Extraction / Visualization
         ↓
       output/

---

## Reproducibility

Keeping source media separate from generated results makes the project easier to:

- Reproduce
- Debug
- Validate
- Compare
- Document
- Extend

The same original input image can be processed repeatedly while preserving previous or newly generated outputs separately.

---

## Generated Subdirectories

The final project may create additional directories inside `output/`.

For example:

    output/
    ├── annotated_segmentation.png
    ├── segmentation_results.json
    ├── masks/
    │   ├── object_00_mask.png
    │   ├── object_01_mask.png
    │   └── ...
    │
    └── extracted_objects/
        ├── object_00.png
        ├── object_01.png
        └── ...

These directories will be created automatically by the Python pipeline when required.

---

## Asset Policy

The project repository should contain:

- Small input images required for reproducibility
- Generated example outputs
- Documentation

The large SAM 3 checkpoint file should **not** be stored in this assets directory or committed to GitHub.

The validated SAM 3 model remains stored externally at:

    /content/drive/MyDrive/SAM3-Models/sam3.pt

This keeps the GitHub repository lightweight while still allowing the complete project to be reproduced in Google Colab.
