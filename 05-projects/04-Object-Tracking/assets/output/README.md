# Output Assets

This directory contains the generated output files from the **Object Tracking with YOLO, Supervision, and ByteTrack** project.

---

## Generated Output

The main output generated by the project is:

```text
tracked_vehicles.mp4
```

The expected path is:

```text
assets/output/tracked_vehicles.mp4
```

---

## How the Output Is Created

The output video is generated by:

```text
object_tracking_pipeline.py
```

The processing pipeline is:

```text
Input Video
     ↓
YOLO Detection
     ↓
Car Filtering
     ↓
ByteTrack
     ↓
Tracker IDs
     ↓
Tracking Analytics
     ↓
Bounding Boxes
     ↓
Labels
     ↓
Object Traces
     ↓
Output Video
```

---

## Output Video Content

The generated video may contain:

- Car detections
- Bounding boxes
- Persistent tracker IDs
- Object class labels
- Frame visibility counts
- Estimated visible time
- Tracking trajectories
- Unique tracked-car count

Example:

```text
car #5 | 42f | 1.40s
```

---

## Input and Output

The original video is stored in:

```text
assets/input/vehicles.mp4
```

The processed result is generated in:

```text
assets/output/tracked_vehicles.mp4
```

This keeps the original source video separate from the generated tracking result.

## Important

Do not manually create:

```text
tracked_vehicles.mp4
```

The tracking pipeline will generate it automatically.

The Python script already uses:

```python
OUTPUT_VIDEO = "assets/output/tracked_vehicles.mp4"
```

and creates the output directory when necessary.

## Reproducing the Output

Run:

```bash
python object_tracking_pipeline.py
```

After successful processing, the generated video should be available at:

```text
assets/output/tracked_vehicles.mp4
```
