# Ground Truth

This directory contains the manually annotated ground-truth data used to evaluate the **Visual Tracking and Analysis System**.

The ground-truth annotations provide reference data for comparing predictions generated by the Project 06 computer-vision pipeline.

---

## Evaluation Dataset

The evaluation dataset contains **20 manually annotated frames**:

- 10 frames from `session_001`
- 10 frames from `session_002`

The selected frames represent different visual conditions and levels of scene complexity.

---

## Annotation Class

The evaluation uses one annotation class:

```text
person
```

Visible people were manually annotated using instance-segmentation polygons.

Partially visible people were annotated according to the portion visible inside the image.

---

## Annotation Method

The evaluation images were manually annotated using a Roboflow **Instance Segmentation** project.

Automatic SAM 3 labeling was not used to create the final ground-truth masks.

This keeps the reference annotations independent from the SAM 3 predictions that will be evaluated.

---

## Export Format

The completed annotations were exported using:

```text
COCO Segmentation
```

The primary annotation file is:

```text
_annotations.coco.json
```

---

## Directory Structure

```text
ground_truth/
├── README.md
└── roboflow_export/
    └── train/
        ├── _annotations.coco.json
        └── [20 evaluation images]
```

The exported images should remain with their original Roboflow filenames because `_annotations.coco.json` references those filenames.

---

## Purpose

This ground-truth dataset supports the evaluation requirements defined in the original Project 06 proposal, including:

- IoU
- Dice coefficient
- Precision
- Recall
- False positives
- Omissions
- Stability under varied conditions

The annotations will be compared against predictions generated by the existing Project 06 pipeline.
