# Output Assets

This directory contains the visual results generated by the **Visual Tracking and Analysis System**.

The outputs are produced by the integrated computer vision pipeline after processing images or recorded videos from the [`../input/`](../input/) directory.

The current project includes a successfully generated final image demonstrating the integration of:

- YOLO object detection
- Supervision detections
- ByteTrack object tracking
- Persistent tracker IDs
- Meta SAM 3 text-prompt segmentation
- SAM 3 segmentation masks
- Combined visualization

## Output Preview

![Final Integrated Pipeline](./final_integrated_pipeline.jpg)

The final visualization contains information produced by multiple components of the system.

### YOLO Detection

YOLO identifies objects in the input image and generates:

- bounding boxes
- class IDs
- class names
- confidence scores

### ByteTrack Tracking

ByteTrack receives the YOLO detections and assigns persistent object identifiers.

Examples of tracker labels include:

```text
#1 bus
#2 person
#3 person
#4 person
```

These IDs form the foundation for persistent object tracking when the system is extended to recorded video.

### SAM 3 Segmentation

Meta SAM 3 receives a text prompt and generates pixel-level segmentation masks for matching objects.

During the final test, the prompt:

```text
person
```

successfully produced four segmentation masks.

### Combined Visualization

The visualization module combines:

```text
SAM 3 Masks
      +
YOLO Bounding Boxes
      +
ByteTrack IDs
      +
Class Names
      +
Confidence Scores
      +
Tracking Visualization
```

into a single annotated output image.

## Output Generation

The final output is generated by the central pipeline implemented in:

[`../../src/pipeline.py`](../../src/pipeline.py)

The pipeline returns a structured result:

```python
{
    "detections": detections,
    "tracked_detections": tracked_detections,
    "segmentation": segmentation_output,
    "annotated_image": annotated_image
}
```

The final annotated image can then be saved using OpenCV:

```python
cv2.imwrite(
    "assets/output/final_integrated_pipeline.jpg",
    final_result["annotated_image"]
)
```

## Visualization Module

Mask overlays, bounding boxes, labels, tracker IDs, and trajectories are handled by:

[`../../src/visualization.py`](../../src/visualization.py)

The visualization order is:

```text
Original Image
      |
      v
SAM 3 Segmentation Masks
      |
      v
YOLO Bounding Boxes
      |
      v
Class Labels
      |
      v
ByteTrack IDs
      |
      v
Object Traces
      |
      v
Final Annotated Image
```

Applying the segmentation masks before the tracking annotations helps keep bounding boxes and labels visible in the final visualization.

