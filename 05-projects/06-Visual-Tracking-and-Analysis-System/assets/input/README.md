# Input Assets

This directory contains the input media used by the Visual Tracking and Analysis System.

## Supported Input

The project is designed to work initially with:

- Images
- Recorded videos
- Short computer vision test sequences

Input files are used for:

- Object detection
- Segmentation
- Object tracking
- Movement analysis
- Model evaluation
- Failure analysis

## Recommended Test Data

During initial development, use:

- 20–50 test images

or

- 2–5 short recorded videos

The input data should include different visual conditions when possible, including:

- Different lighting conditions
- Different object sizes
- Object movement
- Partial occlusion
- Different backgrounds
- Different camera perspectives

## Privacy and Responsible Use

Avoid uploading private or sensitive recordings to the public repository.

When testing tracking involving people, use appropriate:

- Public datasets
- Synthetic data
- Licensed material
- Voluntarily provided test material

Large datasets and videos should not necessarily be committed directly to GitHub.
