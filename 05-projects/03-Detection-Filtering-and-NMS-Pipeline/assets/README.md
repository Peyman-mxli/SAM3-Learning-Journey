# Assets

This directory contains all files used and generated by the Detection Filtering and NMS Pipeline project.

The assets are organized into separate folders for input images and generated output results.

## Structure

```text
assets/
├── input/
└── output/
```

## Input

The `input/` directory contains the original images used by the detection pipeline.

## Output

The `output/` directory contains the processed images generated after applying:

- Confidence filtering
- Class filtering
- Size filtering
- Non-Maximum Suppression
- Top-N selection
- Spatial filtering
