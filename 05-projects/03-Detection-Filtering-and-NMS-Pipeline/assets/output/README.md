# Output

This directory contains the processed images generated by the Detection Filtering and NMS Pipeline.

## Generated Output

The main output generated by this project is:

```text
filtered_detections.jpg
```

The Python pipeline saves the processed image to:

```python
OUTPUT_IMAGE = "assets/output/filtered_detections.jpg"
```

The final image contains detections remaining after applying:

- Confidence filtering
- Class filtering
- Size filtering
- Non-Maximum Suppression (NMS)
- Top-N confidence selection
- Spatial filtering
