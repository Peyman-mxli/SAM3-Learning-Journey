# CSV Results

This directory contains the CSV analytical results generated by **Project 08 — Advanced Mask Analysis Pipeline**.

Each processed input image produces one CSV file containing tabular information about the objects detected by YOLOv8 and segmented by SAM 3.

---

## Expected Files

```text
csv/
├── README.md
├── bus_analysis.csv
└── zidane_analysis.csv
```

The CSV files are generated automatically by:

```text
src/mask_analysis_pipeline.py
```

---

## Naming Convention

Each result follows:

```text
<input_image_name>_analysis.csv
```

Examples:

```text
bus.jpg
   ↓
bus_analysis.csv
```

```text
zidane.jpg
   ↓
zidane_analysis.csv
```

---

## CSV Structure

Each row represents one detected and segmented object.

The columns are:

```text
image
object_id
class_id
class_name
confidence
x1
y1
x2
y2
box_area
mask_area
occupancy_ratio
```

Example:

```csv
image,object_id,class_id,class_name,confidence,x1,y1,x2,y2,box_area,mask_area,occupancy_ratio
bus.jpg,1,0,person,0.91,48.0,398.0,245.0,903.0,99485.0,61234,0.6155
```

---

## Detection Information

The following columns describe the YOLOv8 detection:

```text
class_id
class_name
confidence
x1
y1
x2
y2
```

The coordinates represent the object's bounding box in:

```text
XYXY
```

format.

---

## Mask Analysis

The column:

```text
mask_area
```

contains the number of pixels belonging to the SAM 3 segmentation mask.

The column:

```text
box_area
```

contains the area of the YOLOv8 bounding box.

The column:

```text
occupancy_ratio
```

compares these measurements:

```text
Occupancy Ratio = Mask Area / Bounding-Box Area
```

---

## Purpose

CSV output makes the Project 08 results easy to inspect and analyze using:

- Python
- Pandas
- Spreadsheet applications
- Statistical tools
- Visualization tools
- Data-analysis pipelines

It also makes it possible to compare measurements across multiple detected objects and images.

---

## Relationship to JSON

Project 08 produces both JSON and CSV representations:

```text
Mask Analysis
      ↓
Structured Results
      ↓
├── JSON
│     ↓
│   Hierarchical Representation
│
└── CSV
      ↓
    Tabular Representation
```

JSON preserves the complete result structure for each image.

CSV provides a convenient row-based representation for numerical analysis.

---

## Generation Workflow

```text
data/input/IMAGE
        ↓
YOLOv8
        ↓
SAM 3
        ↓
Mask Analysis
        ↓
Structured Object Records
        ↓
CSV Serialization
        ↓
results/csv/
```

Files in this directory are generated results and should not be edited manually.
