# Results

This directory contains the structured analytical results generated by **Project 08 — Advanced Mask Analysis Pipeline**.

Unlike the annotated images stored in `data/output/`, the files in this directory contain numerical and structured information extracted from the YOLOv8 detections and SAM 3 segmentation masks.

---

## Structure

```text
results/
├── README.md
├── json/
└── csv/
```

---

## Purpose

For every segmented object, the pipeline extracts information such as:

```text
Object
├── Image Name
├── Object ID
├── Class ID
├── Class Name
├── Detection Confidence
├── Bounding Box
├── Bounding-Box Area
├── Mask Area
└── Mask / Box Occupancy Ratio
```

These measurements transform segmentation masks into structured analytical data.

---

## JSON Results

The `json/` directory stores detailed results for each processed image.

Expected files:

```text
results/json/
├── bus_analysis.json
└── zidane_analysis.json
```

Each JSON file contains the image name, total object count, and analytical information for every segmented object.

Example structure:

```json
{
  "image": "bus.jpg",
  "object_count": 6,
  "detections": [
    {
      "image": "bus.jpg",
      "object_id": 1,
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.91,
      "x1": 48.0,
      "y1": 398.0,
      "x2": 245.0,
      "y2": 903.0,
      "box_area": 99485.0,
      "mask_area": 61234,
      "occupancy_ratio": 0.6155
    }
  ]
}
```

Each row represents one detected and segmented object.


---

## Mask Area

Mask area represents the number of pixels belonging to the segmented object:

```text
Mask Area = Number of Non-Zero Pixels in Mask
```

This provides a direct measurement of the pixel-level region identified by SAM 3.

---

## Bounding-Box Area

For a bounding box:

```text
(x1, y1, x2, y2)
```

the area is calculated as:

```text
Box Area = (x2 - x1) × (y2 - y1)
```

---

## Occupancy Ratio

The occupancy ratio compares the SAM 3 segmentation mask with the YOLOv8 bounding box:

```text
Occupancy Ratio = Mask Area / Bounding-Box Area
```

Conceptually:

```text
YOLO Bounding Box
        ↓
Rectangular Detection Region

SAM 3 Mask
        ↓
Pixel-Level Object Region

Mask Area
    ÷
Box Area
    ↓
Occupancy Ratio
```

A higher ratio means the segmented object occupies a larger portion of its detection box.
