# JSON Results

This directory contains the JSON analytical results generated by **Project 08 — Advanced Mask Analysis Pipeline**.

Each processed input image produces one JSON file containing structured information about the objects detected by YOLOv8 and segmented by SAM 3.

---

## Expected Files

```text
json/
├── README.md
├── bus_analysis.json
└── zidane_analysis.json
```

The JSON files are generated automatically by:

```text
src/mask_analysis_pipeline.py
```

---

## Naming Convention

Each result follows:

```text
<input_image_name>_analysis.json
```

Examples:

```text
bus.jpg
   ↓
bus_analysis.json
```

```text
zidane.jpg
   ↓
zidane_analysis.json
```

---

## JSON Structure

Each file contains:

```text
Image Name
    ↓
Object Count
    ↓
Detection / Segmentation Results
```

Example:

```json
{
  "image": "bus.jpg",
  "object_count": 6,
  "detections": [
    {
      "image": "bus.jpg",
      "object_id": 1,
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.91,
      "x1": 48.0,
      "y1": 398.0,
      "x2": 245.0,
      "y2": 903.0,
      "box_area": 99485.0,
      "mask_area": 61234,
      "occupancy_ratio": 0.6155
    }
  ]
}
```

## Object Information

Each object record contains:

```text
image
object_id
class_id
class_name
confidence
x1
y1
x2
y2
box_area
mask_area
occupancy_ratio
```

### Detection Information

```text
class_id
class_name
confidence
x1
y1
x2
y2
```

comes from the YOLOv8 detection associated with the segmented object.

### Segmentation Analysis

```text
mask_area
```

represents the number of pixels contained in the SAM 3 segmentation mask.

### Spatial Analysis

```text
box_area
```

represents the area of the YOLOv8 bounding box.

The relationship between the two is expressed by:

```text
occupancy_ratio
```

calculated as:

```text
Mask Area / Bounding-Box Area
```

## Purpose

JSON provides a structured representation that can be easily reused by:

- Python applications
- APIs
- Dashboards
- Data-processing pipelines
- Computer-vision evaluation tools
- Future analytical systems

The JSON output preserves both detection metadata and segmentation-derived measurements for every analyzed object.

```text
data/input/IMAGE

YOLOv8
        ↓
SAM 3
        ↓
Mask Analysis
        ↓
Structured Object Records
        ↓
JSON Serialization
        ↓
results/json/
```

Files in this directory are generated results and should not be edited manually.
