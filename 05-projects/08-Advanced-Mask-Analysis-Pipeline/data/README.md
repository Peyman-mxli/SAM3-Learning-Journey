# Data

This directory contains the input and generated image data used by **Project 08 — Advanced Mask Analysis Pipeline**.

The project separates original inputs from generated visual outputs so the processing workflow remains organized and reproducible.

---

## Planned Structure

```text
data/
├── README.md
├── input/
└── output/
```

---

## Input Data

The `input/` directory will contain the original images processed by the project.

Initial validation images:

```text
bus.jpg
zidane.jpg
```

These images will be used to test the reusable mask-analysis pipeline across multiple object configurations.

The input workflow is:

```text
data/input/
     ↓
Input Image
     ↓
YOLOv8
     ↓
Object Detections
     ↓
SAM 3
     ↓
Segmentation Masks
     ↓
Mask Analysis
```

---

## Output Data

The `output/` directory will contain annotated images generated by the project.

For each input image, the pipeline will create an analyzed visualization containing:

```text
Original Image
      +
SAM 3 Segmentation Masks
      +
YOLO Bounding Boxes
```

Expected output naming:

```text
bus_analyzed.png
zidane_analyzed.png
```

---

## Separation of Data and Results

The `data/` directory stores image files.

Structured analytical results will be stored separately under:

```text
results/
├── json/
└── csv/
```

Therefore:

```text
data/
    Image Inputs + Image Outputs

results/
    Numerical + Structured Analysis
```

This separation keeps visual evidence and analytical data organized independently.

---

## Supported Image Formats

The current pipeline supports:

```text
.jpg
.jpeg
.png
```

The source code automatically discovers supported images inside:

```text
data/input/
```

---

## Reproducibility

Input images should remain unchanged after being added to this directory.

The pipeline should always generate new outputs inside:

```text
data/output/
```

rather than modifying the original input images.
