# Output Data

This directory contains the annotated images generated by **Project 08 — Advanced Mask Analysis Pipeline**.

The files stored here are visual outputs produced from the original images located in:

```text
data/input/
```

---

## Purpose

For each processed image, the pipeline combines:

```text
Original Image
      +
SAM 3 Segmentation Masks
      +
YOLO Bounding Boxes
```

The resulting visualization provides both object localization and pixel-level segmentation evidence.

---

## Expected Outputs

The initial project inputs are:

```text
bus.jpg
zidane.jpg
```

The pipeline generates:

```text
data/output/
├── README.md
├── bus_analyzed.png
└── zidane_analyzed.png
```

---

## Output Naming

Generated images follow this pattern:

```text
<input_name>_analyzed.png
```

Examples:

```text
bus.jpg
   ↓
bus_analyzed.png
```

```text
zidane.jpg
   ↓
zidane_analyzed.png
```

---

## Visualization Pipeline

```text
Input Image
     ↓
YOLOv8 Detection
     ↓
Bounding Boxes
     ↓
SAM 3 Segmentation
     ↓
Segmentation Masks
     ↓
MaskAnnotator
     ↓
BoxAnnotator
     ↓
Annotated Image
     ↓
data/output/
```

---

## Relationship to Structured Results

This directory contains only the **visual results**.

Numerical and structured analysis is stored separately:

```text
results/json/
results/csv/
```

Therefore:

```text
data/output/
     ↓
Visual Evidence

results/
     ↓
Structured Analytical Evidence
```

---

## Generated Files

The annotated images should not be edited manually.

They are reproducible outputs generated by:

```text
src/mask_analysis_pipeline.py
```

If the pipeline is executed again with the same inputs and configuration, these files may be regenerated or replaced.
